# How to create, install, use and edit ChatGPT Skills

Have you ever wished ChatGPT could follow the same helpful steps every time? A **Skill** gives ChatGPT reusable instructions for a particular task — like a recipe you can use again.

**[Open our free interactive guide →](https://v79sl.com/guides/chatgpt-skills.html)**

This hands-on guide includes six steps for creating a Skill, **four ways to install a new Skill**, an example of **how to use a Skill in ChatGPT**, a copyable Study Buddy prompt, a testing checklist and a four-question quiz.

## What you will learn

1. What a Skill is and why it can help.
2. How to create one in ChatGPT with plain-English instructions.
3. How to install a Skill shared with you by a teammate.
4. How to upload a trusted Skill file or install a plugin containing Skills.
5. How to use an installed Skill in a ChatGPT conversation.
6. How to edit an existing Skill and test your changes.
7. How to share a Skill when your workspace allows it.

## A simple example

Imagine a **Study Buddy** Skill that explains science in easy English, gives examples from everyday life and asks three practice questions. You only need to create the instructions once.
