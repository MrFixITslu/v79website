01 / THE BASICS

First, what's a Skill?

A Skill is a set of instructions that ChatGPT can follow whenever it helps with a particular task. Think of it like a recipe: you write down the steps once, and the assistant follows them again and again.

Easy example: Your Study Buddy skill could explain maths using simple words, show one everyday example and ask you three questions to check what you've learnt.

A skill is not a new AI model. It gives existing AI a reliable way to carry out a job.

02 / FOLLOW ALONG

Create your first Skill

Press Next or choose a step to move through the instructions.

Step 1 of 6
STEP ONE

Open ChatGPT

Visit chatgpt.com and sign in. A laptop or desktop browser makes it easier to follow the instructions.

💡 You can read this guide on one tab and keep ChatGPT open in another.
STEP TWO

Find the Skills page

In the ChatGPT sidebar, choose Plugins, then the Skills tab. If you cannot see it, your account or workspace may not have Skills enabled.

💡 OpenAI currently lists managed Skills for eligible Business, Enterprise, Healthcare and Edu workspaces. The controls may look different on your account.
STEP THREE

Choose how to create it

Select Create, then Create with chat. This is the easiest option for beginners because you can explain what you want in plain English.

💡 Other options may include Create with editor and Upload from your computer.
STEP FOUR

Describe your skill

Give your skill a clear purpose and a few rules. Try the Study Buddy prompt further down this page — just press Copy prompt and paste it into ChatGPT.

💡 Good skill instructions explain who the skill is for, what it does and what a good answer looks like.
STEP FIVE

Review and install

Read the draft ChatGPT creates. Ask for changes if anything is missing, confusing or too complicated. When satisfied, choose Install if it appears.

💡 Never include passwords, secret API keys or someone else's private information in a shared skill.
STEP SIX

Test it with a real question

Start a chat, select or mention your skill if available, and ask: “Explain photosynthesis using simple English.” Does it follow all your rules? If not, edit the instructions and test again.

🎉 That's the whole idea: build → test → improve.
03 / TRY IT YOURSELF

Here's a prompt you can copy

Use this as your first experiment. You can rename the skill, change its audience or replace the topic.

STUDY BUDDY · EXAMPLE PROMPT
Create a skill called Study Buddy.

Its job is to help students aged 13–17 understand difficult school subjects.

Follow these rules:
1. Explain topics using simple English.
2. Give one example from everyday life.
3. Break difficult ideas into small steps.
4. Ask three practice questions.
5. Explain mistakes kindly.
6. Finish with a short summary.
7. Never invent facts.

Make the skill friendly and encouraging.

A Skills creator may ask additional questions before generating the final instructions.

04 / INSTALL A SKILL

How to install a new Skill

There are different ways to add Skills. Choose a method below to see exactly what to do.

Install a Skill someone shared

  1. Open ChatGPT and select Plugins in the sidebar.
  2. Open the Skills tab.
  3. Choose Shared with me or Shared by your workspace.
  4. Find the Skill and select its three-dot menu (•••).
  5. Choose Install.
  6. Go to Installed to check it appears in your list.
💡 If there is no Install option, the Skill might already be installed or your workspace might not allow installation.

Install a Skill file from your computer

  1. Get the Skill file or package from someone you trust.
  2. Read its instructions and check any included code or files.
  3. In ChatGPT, go to Plugins → Skills → Create.
  4. Select Upload from your computer.
  5. Choose your file and follow the prompts.
  6. Allow ChatGPT to scan it. Review any Needs Review warnings. Files marked Blocked cannot be used.
  7. Check Installed when the upload is accepted and available.
🔒 Skills may contain code. A successful scan is not a guarantee that an untrusted file is safe. Never upload secrets or run instructions you do not understand.

Create and install your own

  1. In ChatGPT, open Plugins → Skills.
  2. Choose Create → Create with chat.
  3. Describe what you want. You can paste the Study Buddy example from this guide.
  4. Review and improve the draft.
  5. When prompted, choose Install.
  6. Find your finished Skill under Installed or Created by me.
💡 You can also choose Create with editor to write your own instructions.

Install a plugin that includes Skills

  1. Open Plugins in ChatGPT.
  2. Search or browse the directory for the task you need help with.
  3. Open the plugin and read its description to check which Skills it includes.
  4. Select Install, if available.
  5. Complete any requested setup or account authorisation.
  6. Try the plugin in a conversation. Some plugins contain Skills, some contain connected apps, and some include both.
💡 A plugin is a package that may contain Skills or connected apps. Installing a plugin is not the same thing as uploading a personal Skill file.

The Plugin Directory is available across ChatGPT plans, but personal Skills require an eligible workspace. Features vary by plan, role and administrator settings.

05 / USE YOUR SKILL

How to use a Skill in ChatGPT

After installation, you usually do not need to remember a complicated command. Simply explain what you need. ChatGPT can choose an installed Skill when it fits your request.

  1. Open a new ChatGPT conversation.
  2. Think about what your Skill helps with: studying, creating reports or organising tasks.
  3. Write a normal request that matches the Skill. For Study Buddy, try the example below.
  4. Read the answer and check that it uses the Skill's rules.
  5. If it did not follow the Skill, try mentioning its name or selecting the relevant available plugin with @, where supported, and ask again.
  6. To see what is available, return to Plugins → Skills → Installed.
TRY THIS IN CHATGPT

Using my Study Buddy skill, explain how photosynthesis works. Give an everyday example and ask me three questions.

Remember: ChatGPT can use Skills automatically, but you should still check the answer. A Skill guides the response; it does not guarantee every fact or step is correct.
06 / MAKE IT BETTER

How to edit a Skill

Suppose Study Buddy gives long answers. You can change the instructions instead of starting over.

  1. Open Plugins → Skills.
  2. Find Created by me, then choose Study Buddy.
  3. Open its editing controls, or ask ChatGPT to help modify it.
  4. Add: “Keep explanations under 150 words unless I ask for more.”
  5. Save or update the skill using the option shown.
  6. Ask the original test question again to check the change.
Want more control? Choose Create with editor instead. A skill commonly uses a file named SKILL.md with its name, description and instructions.

09 / COMMON QUESTIONS

Good to know

Can anyone create a Skill?

Not necessarily. OpenAI says managed Skills are available to eligible ChatGPT Business, Enterprise, Healthcare and Edu users, depending on workspace settings. The plugin directory itself may be visible on other plans.

Do I need to know how to code?

No. You can describe your skill in ordinary English using Create with chat. The editor is optional.

Can I share my Skill?

When your workspace allows it, go to Plugins → Skills, open the skill's more-options menu (•••) and choose Share. Check access permissions first.

Is a Skill the same thing as a plugin?

No. A Skill contains reusable instructions. A plugin can package skills with connected apps and other tools.

Where can I read official instructions?

Visit the OpenAI Skills Help Centre. Product menus and eligibility can change.
