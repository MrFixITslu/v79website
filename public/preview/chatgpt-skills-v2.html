PART 01 · GET THE IDEA

A Skill is a saved recipe.

Imagine telling a friend how to make your favourite sandwich. If you explain it every single time, you waste time. If you write down the recipe, they can follow it again.

A ChatGPT Skill works the same way. It is a set of instructions ChatGPT can reuse for a task. You are not creating a new AI; you are teaching the existing AI a repeatable method.

WITHOUT A SKILL

“Explain this simply, add an example and quiz me... again.”

You repeat the instructions.
WITH STUDY BUDDY

“Explain photosynthesis.”

The saved rules do the rest.
Remember: A Skill can help make answers consistent, but ChatGPT can still make mistakes. Check important facts.

PART 03 · YOUR FIRST PRACTICAL

Try building a Skill yourself.

Use this mini builder to write your own Skill instructions. Nothing you type is uploaded to V79 — the text stays in your browser until you copy it.

YOUR SKILL INSTRUCTIONS
Create a Skill called Study Buddy.

Help students aged 13–17 explain difficult school subjects.

Follow these rules:
1. Use clear, simple English.
2. Give a practical everyday example.
3. Break harder topics into short steps.
4. Ask three practice questions.
5. Explain mistakes kindly.
6. End with a short summary.
7. Never invent facts.

Use a friendly and encouraging tone.

PART 04 · INSTALL

How do you install a new Skill?

There is more than one route. Pick the kind of Skill you have; the steps below will change. All methods depend on the options available to your account.

Install a Skill someone shared

  1. Open Plugins → Skills.
  2. Choose Shared with me or Shared by your workspace.
  3. Find the Skill and open its ••• menu.
  4. Select Install.
  5. Check the Installed tab to confirm it is there.
Example: A teammate shares a Meeting Notes Skill with you.

Upload a Skill file

  1. Get a Skill package from someone you trust.
  2. Review its instructions and any included files or scripts.
  3. Open Plugins → Skills → Create.
  4. Choose Upload from your computer.
  5. Select the package, follow the prompts and review security warnings.
Important: Never upload a file with unknown code or private secrets.

Create and install your own

  1. Open Plugins → Skills.
  2. Choose Create → Create with chat.
  3. Describe the Skill. You can use your prompt from the builder above.
  4. Review and improve the generated instructions.
  5. Choose Install when offered, then test it.
This is the easiest route for a beginner.

Install a plugin that contains Skills

  1. Open Plugins in ChatGPT.
  2. Browse or search for the kind of work you want to do.
  3. Check whether the plugin includes Skills or connected apps.
  4. Choose Install if available.
  5. Complete any setup or account permissions, then try it.
A plugin can contain Skills, apps or both. They are not the same thing.

Screens and labels are subject to change. OpenAI's Skills guide is the reference.

PART 05 · USE YOUR SKILL

Use it on a real question.

Once installed, ChatGPT may choose a useful Skill automatically. Where supported, you can also select a Skill by typing @ and choosing it.

PART 06 · IMPROVE

What if the answer isn't good?

Don't delete the whole Skill. Edit the instruction that needs improving, save the changes and test the same question again.

VAGUE RULE

“Keep answers short.”

How short? The instruction leaves room for guessing.
  1. Go to Plugins → Skills → Created by me.
  2. Open the Skill and its editing controls.
  3. Add or improve one clear rule. For example: “Use fewer than 150 words unless I ask for more.”
  4. Save or update it, then repeat your original test.

PART 08 · QUICK ANSWERS

A few things worth knowing.

Can everyone use Skills?

No. Workspace-managed Skills currently require an eligible ChatGPT workspace and administrator settings. Some plugins are available on other plans. Check OpenAI's current availability notes.

Do I need coding experience?

No. You can create a Skill by chatting in simple English. The advanced editor is optional.

Can a Skill read private data?

A Skill itself contains instructions. What ChatGPT can access depends on the tools, apps and permissions available. Never place passwords or sensitive customer data inside shared instructions.

Can I share a Skill?

When supported, open Plugins → Skills, choose the Skill's more-options menu and select Share. Choose who can access it.
