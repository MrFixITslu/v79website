# Quality and release gate

## Educational quality
- [ ] Reader can learn full topic *on this page*, without leaving or sharing.
- [ ] Beginner can understand words and complete a task without prior context.
- [ ] Instructions match currently verified primary documentation.
- [ ] Each key step says what to click, what they should see, and what to do if missing.
- [ ] Has an exercise with an observable success indicator and no fictional claims.
- [ ] Original visuals genuinely explain; illustrations are labelled; sourced screenshots have permission.
- [ ] Source links and review date visible.

## Design and interaction
- [ ] Clear headline, scannable content hierarchy, generous spacing.
- [ ] Native responsive layout works from 360px to desktop (no horizontal scroll).
- [ ] All interactions work with mouse, touch and keyboard.
- [ ] No inaccessible tab state, focus trap, auto-play, or forced scrolling.
- [ ] Reduced-motion option; no content hidden by animations.
- [ ] Copy controls report success only when copy actually works.
- [ ] Contrast and focus visibility checked.
- [ ] Article itself is interactive; not a markdown teaser or nested iframe.
- [ ] Share is optional and after content, not a blocking gate.

## Safety and deployment
- [ ] No secrets, private client data or copied third-party assets.
- [ ] Safe rendering of user input; no untrusted HTML injection.
- [ ] No accidental purchases, sign-ups, external requests or analytics before consent.
- [ ] Noindex on review preview; canonical and metadata on approved published page.
- [ ] Preview and changed files reviewed and tested.
- [ ] Existing production image, app routes and rollback preserved.
- [ ] Owner explicitly approved exact version before replacing live article.
- [ ] Only then test live article/direct share URL and website health.
- [ ] Stop before touching next post.
